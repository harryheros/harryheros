# Nova Infrastructure Toolkit

Building data-driven infrastructure for network intelligence, attribution, security, and system deployment.

---

## Projects

| | Project | Description |
|---|---|---|
| **Data** | [IPNova](https://github.com/harryheros/ipnova) | Routing-aware IP dataset: refined Asia-Pacific regions plus country data from all five RIRs, IPv4 + IPv6 |
| **Data** | [DomainNova](https://github.com/harryheros/domainnova) | Dataset of domains hosted on Asia-Pacific infrastructure, for attribution, compliance, security and network analysis |
| **Data** | [ShieldNova](https://github.com/harryheros/shieldnova) | Compatibility-first domain filter lists for privacy, ad blocking and security |
| **Network service** | [DNSNova](https://github.com/harryheros/dnsnova) | Secure DNS server: recursive with DNSSEC or forwarding, with DoT, DoH and DoQ, for home networks and public resolvers |
| **Tools** | [OsNova](https://github.com/harryheros/osnova) | Deterministic Debian / Ubuntu reinstallation for VPS and bare-metal servers |
| **Tools** | [HarryWrt](https://github.com/harryheros/harrywrt) | Stable OpenWrt-based firmware in two editions, for x86_64, NanoPi, Raspberry Pi and ARM64 VMs |
| **Tools** | [RuleNova](https://github.com/harryheros/rulenova) | An application of IPNova and DomainNova data: region-based rule sets for network clients |

**Data** — datasets for infrastructure intelligence, rebuilt and verified every week.

**Network service** — software that runs a network service in production.

**Tools** — utilities for deploying and operating servers, routers and clients.

---

## Design Principles

- Data-driven, with automated verification
- Compatibility first, minimal breakage
- Precision over volume
- Transparent and reproducible pipelines
